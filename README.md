# alcoholfree (Figma Make)

CRA + SASS 기반 프로젝트를 Vite + React + Tailwind CSS v4로 마이그레이션한 버전입니다.

## 기술 스택

- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **React Router v7**
- **TanStack React Query v5**
- **Lucide React** (아이콘)

## 시작하기

```bash
npm install
npm run dev
```

## 환경변수

`.env` 파일을 생성하고 아래 변수를 설정해주세요:

```
VITE_NOTION_API=https://your-api-url.com
```
